# Installation

## Benoetigte Software

Fuer die ersten Beispiele werden folgende Programme benoetigt:

- Arduino IDE
- USB-Treiber fuer das verwendete Board
- Git fuer die Verwaltung der Beispiele

## Projektablauf

1. Board anschliessen.
2. Passendes Board in der Arduino IDE auswaehlen.
3. Port auswaehlen.
4. Beispiel kompilieren.
5. Programm auf das Board uebertragen.
